# Project Status

Purpose: keep a single, auditable place for project state and backlog.

This folder contains:
- `backlog.md` current items grouped by state.
- `decisions.md` dated choices that shape delivery order.

How to update:
- Move items between states instead of rewriting history.
- Keep IDs stable; update outcome and next action as work evolves.
- Add links to runs, docs, or PRs when available.

Canonical rules:
- This folder is the source of truth for status, backlog, and decisions.
- Roadmaps remain directional; this folder records actual state.
