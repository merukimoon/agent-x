# Feature Definition of Done (DoD)

A feature or refactor is complete only when all of these are true:

- Verify passes (`make verify-fast` or `make verify` as appropriate).
- VerifyFest passes (broader regression and safety checks).
- Verify Flows is executed end-to-end, including gated pause/resume, using the canonical commands.
- Documentation is updated to reflect the current state (flows, contracts, and operator guidance).
